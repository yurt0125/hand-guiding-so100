# VLA Field Dictionary

This document defines the output schema generated by:

```bash
python pipelines/export/export_vla_dataset.py
```

## 1) Meta Fields

- `sample_index`  
  Zero-based sample index in exported dataset.
- `timestamp_s`  
  Timestamp of current sample.
- `timestamp_next_s`  
  Timestamp of next step (`t+1`).
- `delta_t_s`  
  `timestamp_next_s - timestamp_s`.

## 2) Observation Fields

All source trajectory columns are copied with prefix `obs_`, for example:

- `obs_frame_index`
- `obs_frame_path`
- `obs_mid_base_x`, `obs_mid_base_y`, `obs_mid_base_z`
- `obs_base_roll`, `obs_base_pitch`, `obs_base_yaw`
- `obs_hand_found`

Rule:
- For every source column `c`, exported column is `obs_c`.

## 3) Single-Step Relative Action

For state columns configured by `--state-columns` (default below):

- `mid_base_x`
- `mid_base_y`
- `mid_base_z`
- `base_roll`
- `base_pitch`
- `base_yaw`

exported action fields are:

- `action_rel_mid_base_x`
- `action_rel_mid_base_y`
- `action_rel_mid_base_z`
- `action_rel_base_roll`
- `action_rel_base_pitch`
- `action_rel_base_yaw`

Definition:
- `action_rel_state = state(t+1) - state(t)`

## 4) Future Action Chunk

For chunk horizon `H = --chunk-size`, step `k in [1, H]`:

- `action_valid_step{k}`  
  Whether step `k` exists (`True/False`).
- `chunk_delta_t_step{k}_s`  
  `timestamp(t+k) - timestamp(t)`.
- `action_rel_step{k}_{state_name}`  
  Relative action from current state to future step `k`:
  `state(t+k) - state(t)`.

Example (`H=10`):
- `action_valid_step10`
- `chunk_delta_t_step10_s`
- `action_rel_step10_mid_base_x`
- ...

## 5) Notes

- If `--drop-incomplete-chunks` is enabled, tail samples without full chunk are dropped.
- If disabled, tail rows are kept and missing future steps are filled with:
  - `action_valid_step{k} = False`
  - corresponding action columns = `NaN`.
